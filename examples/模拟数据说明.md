# 连续模拟快照

`simulated-sequence.json`包含120帧，每帧间隔500毫秒，共表示约一分钟的模拟过程。所有数值均由程序生成，不是实车采集数据。随机种子固定为20261030，可以重复生成。

在软件“快照回放”中导入这个JSON文件，点击“下一帧”查看。

| 帧（从1计数） | 场景 | 预期表现 |
|---|---|---|
| 1–20 | 主控与巡线持续更新 | 八路模拟读数随位置和噪声变化 |
| 21–44 | 巡线停更，主控继续通信 | 巡线值冻结、年龄增加，记录巡线过期 |
| 45–48 | 状态字段缺失 | 显示未确认，保留原问题 |
| 49–72 | 巡线恢复更新 | 记录巡线恢复 |
| 73–96 | 主控断连 | 记录通信中断，不用旧传感器值判断当前状态 |
| 97–120 | 通信恢复 | 记录通信恢复 |

诊断预期为2次问题出现、2次对应恢复。每帧都带有`simulation.synthetic=true`、相对时间和场景名称。模拟读数和阈值只服务于软件流程演示，未根据实物传感器标定。

重新生成：在源码目录运行`python examples/generate_simulation.py`。
